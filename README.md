# The Vanishing Hour: Duo

Two-player online co-op build of *The Vanishing Hour* — a noir detective point-and-click
mystery. Built with Expo/React Native (landscape-locked, single codebase for web/iOS/Android)
and Supabase (auth, Postgres, realtime) for room pairing and synced game state.

Two detectives create or join a shared room, each pick one of two roles, and go through a
common cold-open intro together before starting the case.

See [SETUP.md](SETUP.md) for how to configure your own Supabase project to run this.
